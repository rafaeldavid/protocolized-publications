What B fixes

  • Retrieval is two-way — the agent queries and context returns, so the hub no longer looks like a sink.
  • "client state" removed from the hub. Live state stays in the source and is queried, not stored — matching the doc's "query the live, ingest the slow" rule. Replaced with the durable "disclosure rules". Ingest is labelled slow-moving.
  • Write-back is gated. The feedback loop passes through an "owner review" step before a lesson is promoted.
  • A legend decodes the five connection types.
Limits the picture still can't show (better said in one line of prose in the doc): the hub is a single dependency that needs access-partitioning and a fallback when it lacks context; and agent writes — to the systems and to the hub — are the part that most needs human gating and audit.

SVG vs. Mermaid — the trade-off

  • Mermaid (C): trivial to edit and version-control, regenerates layout automatically, easy for anyone to update. Less control over exact placement; styling is approximate and the auto-layout won't match the doc's hand-tuned look.
  • Hand-drawn SVG (B): pixel-precise, themes exactly with the page, but every change is manual.
