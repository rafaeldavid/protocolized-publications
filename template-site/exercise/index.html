Subpage purpose

Subpages exist when a report has a companion component — an interactive exercise, a calculator, an embedded tool, a dataset viewer — that deserves its own URL but shares an audience with the main report. See /ai-org/exercise/ for a full-weight example (a drag-drop org-chart canvas).

Chrome consistency

The header, breadcrumb, and keyboard shortcuts match the parent report at /template/. The only differences:

  • The breadcrumb's active class moves to Exercise.
  • The sections overlay lists this subpage's own section ids.
  • The markdown source describes this subpage, not the parent.

The ☰ Sections, ⧉ Copy, and ↓ Download actions all work the same way as on the parent. Readers and agents move between pages with no cognitive overhead.
